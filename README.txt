Бюро ресторанних рішень — сайт №2 (темний, у стилі «фастфуд-вітрини»)

Склад:
  index.html   — весь сайт (HTML, CSS, JS в одному файлі)
  img/         — логотип, фото закладів, кухні, шефа; img/food — фото форматів; img/dishes — страви шефа
  media/       — відео першого екрана й кухні (без звуку) та їхні анімовані копії *-anim.webp:
                 показуються, якщо телефон (iPhone в енергозбереженні) не дає відео запуститися саме

Що замінити перед запуском (пошук у index.html):
  [+380 XX XXX XX XX]           — телефон шефа (шапка й підвал)
  var TELEGRAM = 'https://t.me/' — посилання на Telegram шефа
  var LEAD_ENDPOINT = ''         — адреса, куди надходять заявки (POST JSON: source, name, phone, way, format, page, sentAt)
  var AUTO_POPUP_MS = 60000      — вікно консультації відкривається саме один раз після хвилини гортання (0 = вимкнено)
  VENUE_LINKS                    — посилання «На карті» для закладів

3D-будівлі форматів малюються бібліотекою three.js (підвантажується з cdn.jsdelivr.net, окремих файлів не треба).
Якщо браузер не підтримує 3D, автоматично показуються звичайні намальовані будівлі.

Документи: політика конфіденційності й договір оферти відкриваються у вікні (#privacy, #oferta).
